# Design
**Model.** `song.instruments[]` replaces `song.tracks[]`; `instrument.sound` replaces `track.instrument`. `instrumentDefaults()` fills and clamps `columns`, `mute`, `volume`, `pan` and `INSTRUMENT_SETTINGS` (tune −24..24 whole semitones, cents −100..100, trim −24..24 dB, release 0.25..4). `addInstrument`, `removeInstrument`, `moveInstrument`, `setInstrumentSound` rename the four track functions; `duplicateInstrument(song, id)` adds another from the same sound with the same columns, mix and shaping, no notes, the next free channel and the name numbered on. `phrase.material` is still keyed by instrument id, so nothing else in the file moves. `normalizeSong` reads a format 4 draft that still says `tracks`/`instrument` once and writes it back as instruments; the schema only knows the new shape.

**Sound engine.** Scheduled events already carry their song instrument (`trackRef`) and the sampler already keeps a bus and voices per instrument id, so two instruments from one sound needed only the shaping to come from the instrument: `SamplerSink.setting(instrument)`, `noteOn(..., shaped)`, and the same for `demo` and `audition`. The sketch synth now applies tune and cents too. Sample maps and buffers stay keyed by sound and load once. MIDI out and the .mid export ignore the shaping.

**Instruments panel** (`src/ui/instruments.js`, replacing `tracks.js` and `sounds.js`). A row holds what you change while mixing: name, sound, source badge, ▶, volume, pan, M, S, ⧉ and ⋯. ⋯ opens the rest: tune, cents, trim, release with ↺, channel, columns, the sound's articulations to audition, ↑ ↓ and remove. A row whose shaping differs from its sound shows it beside ⋯ (`+12 −8c −3dB r×2`). Duplicating opens the new row and selects its name. Every change is one song-level undo step; sliders snapshot once per drag. The sound browser is a closed `<details>` so the list stays the subject; it holds the banks bar, the scopes and one row per sound with ▶, articulations and + (with a count of instruments using it). The list does not re-render while a field in it has focus.

**Level sheet.** The phrase and key groups moved as they were, ids and wiring intact, into a panel named `level` with no menu button. `openLevel(scope)` in `src/ui/map.js` sets the key scope, the title and `data-scope`, which hides the phrase group for the song and a section and the key group for a pattern. The ▾ buttons sit beside the crumbs; pressing the same one again closes the sheet.

**Left as it is for now.** Code identifiers and the bank file's `instruments` key, as the proposal says. `state.sound` (samples or synth) keeps its name.

# Design
`#workspace` is a flex row holding `main` and `aside#mixer` (250 px). `mixer.js` rebuilds strips only when the track list changes and updates values in place each frame from a signature, so sliders keep focus. Mute and solo share the song's track flags with the header and the tracks panel. The sidebar state is in `state.mixer` and localStorage `tutti.mixer`; default on at 1100 px and wider. Under 760 px the sidebar is absolutely positioned over the grid. Header groups are `.group[data-label]` with a small uppercase caption drawn by `::before`; on wide screens CSS `order` places song first, then transport, pattern, arrangement, key, entry, output. No JSON change.

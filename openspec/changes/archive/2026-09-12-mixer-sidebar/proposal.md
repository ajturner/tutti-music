# Mixer sidebar and header groups
## Why
The mixer lived in a modal, so balancing while editing meant opening and closing it. The header had grown into an unlabelled run of controls where bpm sat next to the key and the file buttons were far from the song they act on.
## What changes
- A mixer sidebar beside the grid, toggled from the header, remembered per browser, on by default on wide screens and an overlay on phones. Strips show name, mute, solo, volume and pan; the name jumps the cursor to the track.
- The header is grouped and labelled: transport, pattern, song (with save, load, export), arrangement, key, entry, output. The mobile menu shows the same groups as sections.
## Capabilities
- **Modified:** `tracks-and-mixer`, `responsive-layout`
## Non-goals
Meters or automation in the mixer.

# Groove

## Why
Every pattern played dead straight, so reels, scherzos and anything with lilt sounded mechanical. A groove stretches and shrinks rows in a cycle without moving a single note in the grid.

## What changes
- Per-pattern groove: a list of row-length multipliers applied cyclically and normalised so the pattern length is unchanged.
- Presets in the menu (swing eighths light, medium, hard; swing sixteenths) and a custom list.
- Rendering, the playing-row highlight, play-from-cursor and MIDI export all follow the groove.

## Capabilities
- **New:** `groove`
- **Modified:** `song-model` (groove data)

## Non-goals
- Per-track grooves.

# Pattern key
## Why
A B section in the relative major or a modulation made every diatonic tool wrong, because the key was per song.
## What changes
A pattern may override the song key. A "this pattern" toggle beside the key selects edits the override; the status marks a pattern key. All diatonic tools, the pad and the controller use the key in force.
## Capabilities
- **Modified:** `key-and-scale`
## Non-goals
Key changes mid-pattern.

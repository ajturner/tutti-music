# Design
`playHere(loopSection)` in `src/ui/songview.js` is the one way to play from the Song view: Space, Shift+Space, the header's Play button and the controller's Start all call it. It finds the row's first start in the rendered song (`item`, `slot`, first repeats) and calls `playSong(index)`; a section that is not in the arrangement has nowhere to go, so it loops. `setLevel` in `src/ui/map.js` relabels the transport for the level. Counters are `<span class="count">` beside the two repeat fields, filled per frame from the playing start's `sectionRepeat` and `repeat`, only when the count is above one; while a section loops on its own only the phrase count is shown. Follow moves `state.songCursor.row` to the playing row when it changes (not while a field in the view has focus), sets `state.phr` and `state.section`, and scrolls the row into view with `block: 'nearest'`. `Scheduler.positionTick()` clamps to the start position until playback reaches it, so a start in the middle of the song never reports the phrase before it.

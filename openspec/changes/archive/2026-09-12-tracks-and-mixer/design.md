# Design
Core `song.js`: `addTrack` (unique id from the instrument id, first free channel skipping 10), `removeTrack` (drops pattern data), `moveTrack`, `setTrackInstrument` (unsupported articulations become default), `freeChannel`. Track JSON gains optional `volume` (default 100) and `pan` (default 64). Renderer emits CC7 and CC10 per track at tick 0; the preview synth scales its bus gain and drives a stereo panner. UI `tracks.js` builds a `<dialog>` table; slider changes send the controller live while playing. Track edits are song-level and outside the pattern undo history. **Migration:** absent volume and pan read as defaults.

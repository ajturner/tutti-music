The toolbar above the grid applies the same edits, plus velocity, articulation and a linear ramp of velocity, dynamics or tempo across the selected rows. Paste lines cells up by kind, so a block of notes pastes onto note columns and a dynamics run onto a dynamics column.

A new note lasts step rows. Velocity and dynamics take two hex digits; tempo takes up to three decimal digits. Click any cell, or a track name to mute it.

On Windows and Linux use Ctrl wherever ⌘ is shown. Control and Option are never used as modifiers here, because macOS reserves Control with the arrow keys for Mission Control and Spaces, and Option for special characters.

Songs

The song list holds the built-in examples plus anything you create or load. Everything lives in memory until you save: Save .json writes the whole song (patterns, tracks, lanes) as a file; Load .json adds a saved file to the list. Reloading the page discards unsaved songs.

Changing the row size rescales the grid, not the music: ticks stay where they are. Meter sets the bar lines and the exported time signature; 6/8 and 9/8 highlight every third beat.

Examples are written in code with line(), a compact note syntax near the end of the core script. Copy one to sketch a piece in text.

MIDI out to Bitwig and others

Works in Chromium browsers (Chrome, Edge, Arc). Use the published site or a local server (npm start); the app is ES modules, so opening index.html from disk does not work.

macOS: Audio MIDI Setup → IAC Driver → check "Device is online". Windows: install loopMIDI and add a port.

Bitwig: Settings → Controllers → Add → Generic → MIDI Keyboard, input = the IAC bus. On each instrument track set the note input to that controller, channel as shown in the track header, and arm the track. Or drop the exported .mid onto the arranger.

Keyswitches default to C1–G1 (Kontakt displays these as C0–G0). Edit INSTRUMENTS in this file to match your library.

The audio preview is a simple synth for checking voice leading. It is not the sound.

Touch, game controller, MIDI in

Touch: tap a cell to move the cursor, drag to scroll, long-press to clear a cell. The sel pad button switches dragging to selecting. The pad under the grid enters notes and values and appears on touch screens, or tick pad in the menu.

Game controller (Bluetooth or USB; works on iPhone and iPad): d-pad or stick moves the cursor. Hold A and press up/down to nudge the value under the cursor, left/right for an octave. Tap A to enter a note or audition one. B clears, or held with the d-pad extends the selection; X auditions, Y cycles articulation, bumpers change track, triggers jump a bar. With Back held: B copies, X cuts, A pastes, Y duplicates. Start plays or stops the pattern, Back+Start plays the song, Back alone undoes. Press any button after pairing so the browser lists it.

MIDI in: choose an input after enabling MIDI. Played notes go into the cursor cell with their velocity and advance by step; chords spread across the track's note columns. Sustain pedal skips a step; mod wheel writes dynamics. Not available on iOS, which has no WebMIDI.

# Bundled samples

The audio in this folder is derived from **VSCO 2 Community Edition** by Versilian Studios
(https://github.com/sgossner/VSCO-2-CE), released under CC0 1.0 (public domain dedication).
Files were trimmed, faded, downmixed to mono and encoded to AAC by `scripts/build-samples.mjs`.
Each `map.json` records the source file of every zone. The converted files are likewise CC0.
